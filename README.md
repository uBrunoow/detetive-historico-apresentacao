# Detetive Histórico · Apresentação

Apresentação do projeto final de Informática na Educação (TADS · UDESC, 2026) sobre o **Detetive Histórico**, um jogo de investigação para o ensino de História pela análise de fontes.

- Jogo: https://detetive-historico.vercel.app
- Código do jogo: https://github.com/uBrunoow/detetive-historico

## Como apresentar

Abra o `index.html` no navegador (ou o endereço publicado na Vercel). É um site estático, sem build.

| Tecla | Ação |
| --- | --- |
| → / Espaço | Próximo slide ou passo |
| ← | Slide anterior |
| O | Parede com todos os slides |
| N | Notas do apresentador e cronômetro |
| F | Tela cheia |
| P | Exportar PDF |
| K | Paleta de comandos |
